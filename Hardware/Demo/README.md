Demo video placeholder

Place your demonstration video in this folder as `demo.mp4` OR upload the video to YouTube and paste the link in the main `README.md` as shown below.

How to add a local demo file:

1. Copy `demo.mp4` to `Hardware/Demo/`.
2. Commit and push.

Note: GitHub will not stream large videos directly in the README; uploading to YouTube and embedding the link is the recommended approach.

Example YouTube embedding snippet for `README.md`:

```
[![Demo video](https://img.youtube.com/vi/<VIDEO_ID>/0.jpg)](https://www.youtube.com/watch?v=<VIDEO_ID>)
```
